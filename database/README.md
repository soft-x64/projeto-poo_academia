# Pasta database

Esta pasta é responsável por armazenar os arquivos relacionados ao banco de dados do sistema.

## O que deve ser colocado aqui

- Scripts de criação do banco de dados.
- Scripts de criação das tabelas.
- Scripts de inserção de dados iniciais.
- Arquivos de configuração/conexão com o banco, se necessário.
- Diagramas ou documentação relacionada ao modelo do banco.

## Exemplos de arquivos futuros

- `schema.sql`  
  Arquivo com a criação das tabelas do sistema.

- `seed.sql`  
  Arquivo com dados iniciais para teste.

- `connection.py`  
  Arquivo responsável por conectar o sistema ao banco de dados.

## Responsabilidade da equipe

Quem trabalhar nesta pasta deve garantir que o banco esteja organizado, com tabelas bem definidas e compatíveis com as funcionalidades do sistema de academia.
