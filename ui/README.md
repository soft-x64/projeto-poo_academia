# Pasta ui

Esta pasta é responsável pela interface do sistema.

## O que deve ser colocado aqui

- Telas do sistema.
- Menus interativos.
- Formulários de cadastro.
- Interface web, desktop ou via terminal.
- Arquivos visuais, se o sistema tiver frontend.

## Exemplos de arquivos futuros

- `menu.py`  
  Menu principal do sistema no terminal.

- `cadastro_aluno.py`  
  Tela ou função responsável pelo cadastro de alunos.

- `listar_alunos.py`  
  Tela ou função responsável por exibir alunos cadastrados.

- `pagamentos.py`  
  Tela ou função responsável pela visualização e atualização de mensalidades.

## Exemplos de responsabilidades

- Mostrar opções para o usuário.
- Receber dados digitados.
- Exibir mensagens de erro ou sucesso.
- Chamar os services para executar as ações do sistema.

## Responsabilidade da equipe

Quem trabalhar nesta pasta deve focar na interação com o usuário.  
A interface não deve conter regras complexas de negócio nem comandos SQL diretamente.
